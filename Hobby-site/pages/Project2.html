Project Details

Status: Completed!

This project is a small weather station built with an ESP32 microcontroller connected to a temperature and humidity sensor. The ESP32 reads the sensor and shows the current readings on a small OLED display, so the conditions in the room can be checked

Components

  • ESP32 microcontroller
  • OLED display screen
  • Temperature and humidity sensor
  • Power supply
