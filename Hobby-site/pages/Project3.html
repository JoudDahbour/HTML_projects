Project Details

Status: In Progress!

This project is a prosthetic controlled by muscle signals. It uses an ESP32 microcontroller, five servo motors to move fingers, and EMG electrodes that read muscles, so when user flexes, the hand responds. The electronics and constrol side are working; what's left is the 3D model of the hand itself, which still needs to be designed and 3D printed.

Components

  • ESP32 microcontroller
  • 5 servo motors (one for each finger)
  • EMG electrodes to read muscle signals
  • 3D printed parts for the hand structure
